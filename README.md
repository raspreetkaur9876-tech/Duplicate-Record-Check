# Duplicate Record Check — Data Analytics Project

## Project Overview
This project uses Microsoft Excel to identify repeated product names, check for duplicate records, and summarize data quality findings in a retail product dataset.

## Objectives
- Identify repeated product names.
- Use Excel formulas to check duplicate values.
- Classify product names as Duplicate or Unique.
- Prepare a duplicate report.
- Summarize findings in a project summary sheet.

## Tools Used
- Microsoft Excel
- Excel formulas: `COUNTIF`, `COUNTA`, and `IF`
- Conditional Formatting
- Filters and Tables

## Project Workflow
1. Load the retail product dataset.
2. Check Product IDs and Product Names for repeated values.
3. Use Conditional Formatting to highlight repeated product names.
4. Apply Excel formulas to classify repeated and unique names.
5. Create a separate duplicate report.
6. Prepare a project summary and cleaned dataset.

## Project Files
- `Duplicate_Record_Check_Corrected.xlsx` — Excel workbook containing the dataset, duplicate report, summary, and cleaned data.

## Key Learning Outcomes
- Learned how to identify repeated values in Excel.
- Practiced using formulas for data-quality checks.
- Organized findings into a separate report.
- Improved skills in data cleaning and data analysis.

## Conclusion
This project demonstrates a basic data-quality checking process using Excel. It helps identify repeated product names and organize the findings for further review.

**Note:** Repeated product names do not necessarily mean that complete records are duplicates. Records should be compared across relevant columns before being removed.
